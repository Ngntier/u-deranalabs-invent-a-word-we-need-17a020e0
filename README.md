**doorblank — the sudden blank that erases why you entered a room the moment you cross its doorway.**

Everyone has felt it: you walk into a room with a purpose, cross the threshold, and the reason is simply gone. Psychologists call it the doorway effect, but English has no everyday word for the blank itself. *Doorblank* fills that gap — door + blank, sayable, spellable, and instantly recognisable the first time you hear it.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly one line with no trailing newline.

## Entry
